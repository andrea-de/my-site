## Work

- **Sales forecasting for a car maker.** For an international automobile company's sales department, built the front end of a sales forecasting run, the services and the visualisations around the forecasting model. Everything except the model itself was built in Python and Django and run in Docker Compose.
- **Data extrapolation.** Developed NumPy and pandas logic extrapolating each forecasting run's settings into many model inputs, so one run produced many forecasts.
- **RNA sequencing analytics.** Built the interface in Java and JSP and the automated report generation for an RNA sequencing analytics tool.
- **Data science infrastructure.** For other deliverables, in industries such as manufacturing, supported data science solutions with infrastructure that connected model runs to their outputs and visualisations, presented with reusable Plotly and D3 components.
