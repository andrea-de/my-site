## 1. Volumetric 3D Spatial Geometry Library

A core engineering challenge was mapping chemical sensor readings and physical drill-core assays onto real-time 3D models of stockpiles and excavation faces:

- **Voxel-to-Column Transformations**: Authored a high-performance Python mathematics library using **NumPy** and **SciPy** that translated irregular, high-resolution 3D voxel grids into columnar representations for fast spatial simulation.
- **Interactive 3D Visualizations**: Built custom spatial analytical dashboards using **Plotly** and WebGL, allowing metallurgists and mining engineers to inspect material grade distributions in 3D space.

- **Edge Deployment & Containerization**: Packaged microservices into hardened Docker containers deployed to Kubernetes clusters operating both in cloud environments and on-premise industrial gateways.
