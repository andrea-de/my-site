## Where Andrea used it

- **[AIA](/tree/roles/aia) (2018).** Containerised Python and Django services to orchestrate and deploy predictive model runs.
- **[Giesecke+Devrient](/tree/roles/gandd) (2018 to 2020).** Java and Spring microservices for high-volume telecom message delivery, with test suites run in CI/CD.
- **[Intellisense.io](/tree/roles/intellisense) (2020 to 2022).** Node.js services packaged in Docker; containerised artifact delivery on Docker, Kubernetes and Azure, synchronised with client engineering teams.
- **[Mesa Cloud](/tree/roles/mesa-cloud) (2022 to 2023).** Scalable environments on AWS Elastic Beanstalk, including network policies, for horizontally scaled ETL workers.
- **[Autonomic Alpha Foundry](/tree/prototypes/foundry).** Self-hosted as a Docker stack of engine, UI, broker and Postgres.
- **Since 2023.** The Advection estate runs managed services instead; see [Google Cloud](/tree/tech/google-cloud). Its CI runs on owned hardware; see [deployment pipelines](/tree/architecture/deployment-pipelines).
